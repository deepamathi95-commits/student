# 📚 Student Result Management System

## 📌 Description

A Python-based Student Result Management System that allows users to manage student details and calculate their results.

## ✨ Features

* Add student details
* View student details
* Calculate total marks
* Calculate average marks
* Display student grade
* Store student data using CSV
* Object-Oriented Programming
* Functions and lists

## 🛠️ Technologies Used

* Python
* OOP
* Lists
* Dictionaries
* Functions
* CSV File Handling

## ▶️ How to Run

Open the terminal in this project folder and run:

```bash
python main.py
```
